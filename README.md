# Koru Florya

Koru Florya AVM için hazırlanmış Türkçe, responsive tanıtım sitesi.

## İçerik

- Premium, doğal renk paleti ve mobil uyumlu arayüz
- Koru, Podyum ve Cadde katları arasında geçiş yapılabilen, aranabilir mağaza örnekleri
- Ziyaret saati, adres, ulaşım, otopark, kat planı ve resmi mağaza dizini bağlantıları

Mağaza örnekleri resmî dizinde yer alan listelerden seçilmiştir; bütün katların eksiksiz canlı dizini değildir. Güncel işletme ve ziyaret bilgileri için site içindeki resmî Koru Florya bağlantılarını kontrol edin.

## Çalıştırma

`index.html` dosyasını tarayıcıda açabilir veya statik web sunucusunda yayımlayabilirsiniz. Fotoğraflar ve yazı tipleri harici servislerden yüklenir.
